## 4. Salesforce Comparison

### Overview

| Aspect | HubSpot | Salesforce |
|--------|---------|------------|
| **Founded** | 2006 | 1999 |
| **Market Share** | Growing (SMB leader) | 19.5% (#1 overall) |
| **Target Market** | SMBs and mid-market | Mid-market to Enterprise |
| **Philosophy** | Ease of use, all-in-one | Customization, extensibility |
| **CRM Approach** | Opinionated, guided | Highly flexible, configurable |

### Salesforce Pricing (Sales Cloud)

| Plan | Price | Key Features |
|------|-------|--------------|
| Starter Suite | $25/user/mo | Basic CRM, account/contact/lead management, email tools, dashboards |
| Pro Suite | $100/user/mo | Everything in Starter + enhanced customization, automation, quoting, forecasting, Lightning App Builder |
| Enterprise | $165/user/mo | Everything in Pro + advanced pipeline management, territory management, opportunity insights |
| Unlimited | $330/user/mo | Everything in Enterprise + premier support, sandbox, workflow automation |
| Einstein 1 Sales | $500/user/mo | Everything in Unlimited + Einstein AI, Data Cloud, Revenue Intelligence |

### Detailed Comparison

| Category | HubSpot | Salesforce |
|----------|---------|------------|
| **Ease of Use** | Very intuitive, minimal training needed, drag-and-drop UI | Steeper learning curve, requires admin training, Trailhead platform for learning |
| **Setup Time** | 36-day average activation | Months-long setup, often requires consultants |
| **Free Plan** | Yes (robust, with limits) | No free plan (15-day trial only) |
| **Customization** | Moderate -- growing with custom objects, UI extensions | Extensive -- custom objects, Apex code, Lightning components, Visualforce |
| **App Ecosystem** | 2,000+ apps in marketplace | 4,000+ apps on AppExchange |
| **Marketing Tools** | Native, deeply integrated Marketing Hub | Requires Marketing Cloud (separate purchase, $1,250+/mo) |
| **AI Capabilities** | Breeze AI (agents, copilot, smart features) | Einstein AI / Agentforce (more customizable but complex) |
| **Reporting** | Good, with custom reports at Pro+ | Very powerful, highly customizable at all tiers |
| **API & Development** | REST APIs, UI extensions, custom code actions | SOAP/REST APIs, Apex, Lightning Web Components, Visualforce |
| **Support** | Email/chat (Starter), phone (Pro+) | Community only (free), Premier ($$$), or 30% of license fees |
| **Implementation Cost** | $1,500-$7,000 onboarding | $10,000-$100,000+ typical implementation |
| **Total Cost (10 users)** | ~$1,000-$2,500/mo (Pro suite) | ~$1,650-$5,000/mo (Enterprise) |

### When to Choose Each

**Choose HubSpot when:**
- Small to medium-sized business (under 200 employees)
- Want fast implementation and minimal training
- Need integrated marketing + sales + service
- Budget-conscious with predictable costs
- Inbound marketing is a priority
- Want a free tier to start

**Choose Salesforce when:**
- Large enterprise with complex sales processes
- Need extensive customization (custom objects, code, workflows)
- Require advanced reporting and analytics
- Have dedicated Salesforce admin resources
- Need industry-specific solutions (Financial Services Cloud, Health Cloud)
- Complex multi-territory, multi-currency operations

### Key Competitive Insights for F-CORE

1. HubSpot is winning on **ease of use** and **time to value** -- F-CORE should prioritize this
2. Salesforce's **customization depth** is hard to replicate but also its biggest barrier
3. HubSpot's **all-in-one approach** (CRM + Marketing + Sales + Service) is its strongest differentiator
4. **AI integration** is the new battleground -- both platforms are investing heavily

- Budget is tight and predictable per-user pricing is important

- Fast setup needed with minimal training

**Choose HubSpot when:**
- Need marketing + sales + service in one platform
- Growing team that will need more tools over time
- Want free CRM to start
- Content marketing is important
- Need customer service tools

### Key Competitive Insights for F-CORE

1. Pipedrive proves that **exceptional pipeline visualization** alone can build a successful CRM company
2. **Simplicity wins** for small sales teams -- F-CORE should have a "sales-first" simple mode
3. Pipedrive's **per-user pricing** is more transparent -- important for F-CORE pricing strategy
4. Pipedrive lacks marketing/service -- this is HubSpot's advantage that F-CORE should replicate
5. The **deal rotting** feature (visual indicator when deals stall) is a beloved Pipedrive innovation

- **Search:** Object-specific search bar
- **Record Preview:** Hovering/clicking shows preview sidebar

| **P1 - Essential** | Reporting Dashboard | Data visualization |

| **P3 - Advanced** | Quotes & Invoicing | Commerce tools |
| **P3 - Advanced** | Advanced Reporting | Custom analytics |
| **P3 - Advanced** | AI Features | Modern differentiator |

### 7.2 Key Differentiators to Build

| Differentiator | Strategy |
|---------------|----------|
| **No contact limit on free tier** | Unlike HubSpot's 1,000 limit, offer generous free tier |
| **Transparent pricing** | Simple per-user pricing like Pipedrive, not HubSpot's complex tiers |
| **Open source advantage** | Self-hostable, customizable, no vendor lock-in |
| **Modern tech stack** | Next.js, React, Supabase -- faster, more modern than legacy CRM |
| **AI-native** | Built with AI from day 1, not bolted on |
| **Developer-friendly** | API-first, webhook-first, extensible |

### 7.3 UI/UX Clone Priorities

1. **3-column record layout** -- This is the most recognizable HubSpot pattern
2. **Collapsible left sidebar navigation** -- Clean, icon-based, expandable
3. **Data table with quick filters + saved views** -- Essential for data management
4. **Kanban pipeline board** -- Deal/ticket management cornerstone
5. **Activity timeline** -- Communication history tracking
6. **Dashboard with draggable widgets** -- Reporting and analytics
7. **Slide-out creation panels** -- Modern record creation pattern
8. **Global search (Cmd+K)** -- Quick navigation

### 7.4 Technical Architecture Insights

- HubSpot's platform is built around **objects** (Contacts, Companies, Deals, Tickets, Custom Objects)
- Every object has **properties** (fields) that can be customized
- Objects are connected via **associations** (many-to-many with labels)
- **Activities** (emails, calls, notes, tasks, meetings) are tracked across all objects
- **Pipelines** with customizable stages are used for Deals and Tickets
- **Lifecycle stages** track contact journey: Subscriber > Lead > MQL > SQL > Opportunity > Customer > Evangelist
- **Lead status** tracks current sales activity: New > Open > In Progress > Open Deal > Unqualified > Attempted to Contact > Connected
- **Workflows** automate actions based on triggers and conditions
- **Teams and permissions** control access at object, record, and field levels
